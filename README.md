# Homelab

This project is my way of learning tools/devices that I see in the real world at home.

## Overview

I want this to be used mainly as a learning platform for me to use things like proxmox hosts, offensive security tools, defensive security tools and whatever else I may decide to add later all separated on different vlans.

## Current status
Phase 0: planning implementation and doing inventory logging.

## Repo structure

- `inventory.csv` — physical asset tracking
- `network/ip-plan.md` — IP addressing and topology docs
- `docs/decisions.md` — log of design decisions and why

## Roadmap

Phase 0: Get all devices and equipment logged and plan out next steps
Phase 1: Have all devices configured and running on one flat network for any additional setup that is needed 
Phase 2: Have a switch level vlan for the network
Phase 3: Have a router/firewall for enforcement on the lab vlans
